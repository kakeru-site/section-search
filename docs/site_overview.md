# 1. このサイトは何か（目的）

## 1.1 ひとことで

**日産の部品を扱う店頭スタッフが、お客さんの話を聞きながら、すばやく「部品名・図番（部品コード）・セクション」にたどり着くための、自分専用の業務ツール**です。あわせて、見積りの計算、バルブ・オイル・スフィアライトの商品検索、外装や内装・機関の部品の学習・検索ができます。

## 1.2 作った目的

| 目的 | 内容 |
|---|---|
| ① 店頭で、すぐ調べる | お客さんの言葉（「ドラシャのブーツ」「バックカメラが映らない」など）から、部位と図番を出す |
| ② 新人の学習 | 部位ごとの「絵」と「やさしい説明」と「分類」で、部品の全体像をつかめるようにする（店頭歴の浅い人が、先輩に聞く前に調べられる） |
| ③ 計算のミスを減らす | 売価・原価・パッド／ローターの計算を、入力するだけで自動にする |
| ④ 社内の資料づくりを楽に | 検索結果や商品の一覧を、見やすいExcel（印刷用つき）に、ワンボタンで書き出す |
| ⑤ 調べたことを残す | メモ・検索履歴・追加した部品を、どの端末からも見られるようにする |

## 1.3 想定する使い手

- 部品の知識はあるが、店頭の経験が浅い人（店頭に立って数か月）
- お客さんが、部品名ではなく、「症状」や「通称」で話してくる場面が多い人
- パソコンとスマートフォンの両方で使う人（自分専用。本人だけがログインして使う）

# 3. 主な機能の説明

## 3.1 セクション検索（いちばん使う画面）

- **あいまい検索**：部品名の一部、ひらがな、全角・半角、部品コード、セクション番号で探せる。
- **読み（ひらがな→漢字）**：「もれ」で「漏れ」のように、ひらがなで探せる辞書を持っている。
- **同義語**：言い方の違い（例：通称と正式名）を、設定で足せる。
- **結果からの操作**：Googleで調べる／メモに残す。セクション番号を押すと、同じセクションの部品を一覧にする。
- **外装・部品の部位カード**：検索に合う部位があれば、絵と説明つきのカードが同じ画面に出る。押すと、外装検索・部品検索の画面に移る。

## 3.2 型式 → 車種

- 型式を入れると、対応表から車種名を判定する。
- 未登録の型式は、Googleで調べて、その場で登録できる（登録した内容は、次から使える）。
- 「確認済み」「未確認」の印で、データの信頼度が分かる。

## 3.3 メモ・検索履歴

- 業務中の疑問を、部品や型式に結びつけて残す（自動保存）。
- 履歴は、検索した言葉・件数・日時を残し、押すと同じ検索をやり直す。

## 3.4 計算ツール（売価・原価・パッド／ローター）

- 入力したそばから、計算する（Enterで次の行へ。Excelからの貼り付けもできる）。
- パッド・ローターは、セット価格（普通車・軽自動車）と原価から、ローター1枚の値段を出し、原価割れのときは、パッドとローターの振り分けを変える。それでも足りないときは、「値引きが必要」と表示し、提案の売価を出す。
- 掛け率、上乗せ、端数のしかた（5円↑、10円↓など）は、設定で変えられる。

## 3.5 バルブ検索・解説書

- バルブの規格（例：H4、H11、T10）・電圧・用途で探す。
- **解説書**：形状ごとに、使う場所、見分け方、接客のポイント、注意、豆知識、模式図をまとめた学習用の資料。店のバルブデータと結びついている。
- ピットワークのカタログと照らして、データを直した履歴がある。

## 3.6 オイル・ケミカル／スフィアライト

- 商品の用途・規格・容量で検索できる。
- スフィアライトは、シリーズ（例：ライジング）と形状、色温度ごとの**品番早見表**（A4たて1枚で印刷できる）と、**補足資料**（取り付けの難しさ、加工の解説など）がある。

## 3.7 外装検索

- 外装の部位（フロントバンパー、グリル、フェンダー、ボンネット、ドア、バックドア、ルーフ、床まわりなど、約38部位）と、部品の名称・図番・右左・備考を持つ。
- 部位ごとに、**車の簡単な図（どこにある部品か）**、やさしい説明、お客さんの呼び方を載せる。
- 「絵から探す」：車の正面図の、押せる場所から、部位に移れる。
- 自分の店の写真を、部位のページに登録できる。
- 小さな部品（ボルト・クリップなど）は、一覧に載せない方針（部位の絵で場所を確認する）。
- 分類：フロント、室内、ルーフ・ガラス、床、サイド、ドア、リア。

## 3.8 部品検索（内装・機関）

- エンジン、冷却、電装、ミッション・駆動、足回り、ブレーキ、空調、内装などの部位（約120部位）と、部品の図番を持つ。エンジンの型式は書かない（目的は、部品コードを知ること）。
- 部位ごとに、形のイメージの絵、やさしい説明、お客さんの呼ばれ方を持つ。絵は、部位ごとに色合いと名前が違い、フロント・リアには「前」「後」の印が付く。
- **分類**（学習しやすい順）：エンジン本体／吸気・排気・燃料／冷却／電装・制御／ライト／空調／ミッション・駆動／足回り・タイヤ／安全装置（シートベルト）／シート／ミラー・エアロ／内装・その他／ステアリング／ブレーキ。
- 備考には、**お客さんの呼び方と、部品がある場所**を書く（例：「デフのサイドシール」「前側のシール」）。位置を図から推測したものは、「要確認」と書く。

# 4. Excelへの書き出し

どの機能も、同じデザイン（黄色い見出し、入力は黄色いセル、使い方シートつき）で書き出せる。

| 書き出す内容 | シート |
|---|---|
| 売価・原価・パッド／ローター | 空の計算表（20行は枠つき、100行まで数式。使い方つき） |
| オイル・ケミカル | 検索、使い方、印刷用、データ |
| バルブ | 検索、解説書（画面用・A4印刷用）、データ |
| スフィアライト | 検索、補足資料（画面用・印刷用）、品番早見表 |
| 外装＋部品 | 探せる一覧（言葉を入れると、当てはまる部品だけが並ぶ）、部位カタログ（絵つき・A4よこ印刷）、全部のデータ、使い方 |

- **シート保護**：入力できるのは黄色い欄だけ（パスワードなし。外せる）。
- **会社のExcelに追加**：今ある会社のExcelの、後ろに、シートだけを足して、別ファイルとして保存する（元のファイルは変えない）。
- 数式は、Excel 2016までの関数だけを使い、マクロは使わない。

# 5. データの扱い

## 5.1 データの置き場所（Firebase Realtime Database）

```
sectionApp/
  parts/{id}      部品（セクション、コード、名称、備考、頻出）
  kata/{型式}     型式と車種名（確認済みかどうか）
  memos/{id}      メモ
  history/{id}    検索履歴
  settings/       設定（Google検索、同義語など）
  exteriors/      外装の部品（部位、名称、英語名、図番、右左、備考）
  extGroups/      外装の部位の追加分
  extPhoto/       外装の、店の写真
  inners/         部品（内装・機関）
  innGroups/      部位の追加分
  innPhoto/       部品の、店の写真
  oils, bulbs, spheres など  商品データ
```

## 5.2 取り込み

- Excel・CSV・JSONから取り込める（列：部位／名称／英語名／図番／右左／備考）。
- 同じ「部位＋図番＋右左」は、上書きされる（二重にならない）。
- **重複の確認**：すでに同じ図番がある部品は、取り込み前の画面で、件数が出る。「飛ばして取り込む（おすすめ）」か「置き換えて取り込む」を選べる。別の車を足すときは「飛ばす」、備考を直して入れ直すときは「置き換える」。
- バックアップ：全データを、1つのファイルに保存・復元できる（外装・部品の写真も含む）。

## 5.3 守っていること

- 部品データ（EPCの内容）は、公開されるサイトのファイルには置かず、ログインした本人だけが読めるFirebaseに入れている。
- コードは公開リポジトリにあるが、データは入っていない。
- PARTSOUQなどの画像は、そのまま使わず、自分で作った簡単な絵だけを使っている。
- 部品データは、お店の中だけで使う。外に出さない。

# 6. 仕組み（技術のまとめ）

## 6.1 全体

- **画面**：GitHub Pages で配信する静的なサイト（HTML、CSS、JavaScript。ビルド作業なし）。
- **データとログイン**：Firebase（メール＋パスワードのログイン、Realtime Database）。本人のUIDだけが、読み書きできるルール。
- **デモモード**：設定のAPIキーが空だと、ログイン不要・ブラウザ内だけに保存して動く（試用・テスト用）。
- **生体認証ロック（任意）**：Face ID／Windows Hello／指紋で、端末ごとにロック解除できる。
- **Googleカスタム検索の埋め込み（任意）**：型式が未登録のとき、アプリ内に結果を出せる。

## 6.3 工夫

- **更新の反映**：ファイルの読み込みに、版の番号（例：`?v=20261019k`）を付けて、古い表示が残らないようにしている。外装・部品検索の画面の下に、今の版が出る。
- **絵**：部位の絵は、プログラムで描いたSVG。Excelに入れるときは、PNGに変えて、貼る。
- **Excel**：ExcelJSで作り、JSZipで会社のExcelに差し込む。LibreOfficeで、表示と印刷を確かめている。
- **印刷**：A4に合わせて、ページが途中で切れないように、区切りを計算している（部位カタログ、補足資料、早見表）。

# 7. 毎日の使い方（流れ）

1. お客さんの話を聞く（部品名、症状、通称）。
2. 「セクション検索」に、聞いた言葉を入れる。部位カードや部品が出る。
3. 図番を見つけたら、**必ず、EPCや車台番号で、車に合うかを確かめてから**、注文する。
4. 分からないことは、メモに残す。解決したら、「解決済み」にする。
5. 「こう聞かれた」を見つけたら、備考に足す（ツールが育つ）。
6. 時間のあるときは、「部品検索」を、分類順に眺めて、学習する。
7. 資料が必要なときは、Excelに書き出して、印刷する。

# 8. 気をつけること・限界

- **図番は候補**：車種・年式・仕様で、図番が違うことがある。注文前に、必ず確認する。
- **車種の欄がない**：外装・部品のデータは、車種ごとに分けていない。別の車を足すときは、取り込みの確認画面で、重複を見る。数台を超えるなら、車種ごとに分ける機能が必要。
- **推測の情報**：図から推測した位置・左右は、「要確認」と書いてある。実車で確かめたら、直す。
- **絵は目安**：形のイメージで、実物と細部が違う。
- **Excelの動作**：LibreOfficeで確認しているが、実際のExcelやプリンターで崩れたら、直す。
- **データの持ち出し**：EPCの内容は、お店の中で使う。外に出さない。
- **バックアップ**：大きくデータを入れ替える前に、バックアップを保存する。

# 10. 用語

| 言葉 | 意味 |
|---|---|
| 図番 | 部品の図の中の番号（部品コード）。注文用の部品番号とは別。例：62050 |
| EPC | メーカーの電子部品カタログ |
| 部位 | 部品が属するまとまり（例：フロントバンパー、ブレーキ配管） |
| 備考 | お客さんの呼び方、部品の場所、仕様の違いなどのメモ |
| 要確認 | 図から推測した情報で、実車での確認が必要なもの |
| 掛け率 | 定価に対する割合（75掛け＝定価の75%） |
| 仕切り | 仕入れ価格（原価） |
